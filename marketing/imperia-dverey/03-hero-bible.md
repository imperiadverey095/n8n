# Герой сериала — библия персонажа

## Кто он
- **Реальный человек по фото**, с его письменного/устного согласия на ИИ-генерацию его образа и голоса.
  Кандидат — владелец, Асхаб Минкаилов (@askhab.minkailov) **[подтвердить]**.
- Роль в сериале: **«эксперт, который видел все ошибки покупателей»**. Не продавец, а
  советник: «я лучше отговорю, чем продам не то».
- Возраст и образ: солидный, спокойный, уверенный. Говорит коротко, по делу, с лёгкой иронией.
  Это вызывает доверие у аудитории 35–65 лет.

## Внешний вид (фиксируем во всех сериях)
- Одежда: тёмно-графитовая рубашка или водолазка, тёмный пиджак без галстука, часы.
  Никаких логотипов чужих брендов.
- Причёска и борода — как на фото-референсах, не меняем.
- Рекомендуемые референсы: 3–5 фото — анфас, 3/4 слева и справа, в полный рост; ровный дневной
  свет, без очков и головного убора (если только это не часть постоянного образа).

## Локации (повторяются из серии в серию)
1. **Шоурум** (Сайханова, 172): ряд дверей, тёплый свет, дуб и матовый чёрный. Основная точка
   для разговора в камеру.
2. **Объект клиента**: дом в процессе ремонта / готовый интерьер. Точка для демонстраций.
3. **«Чёрная студия»**: тёмный фон и контровой свет. Для VFX, крупных планов продукта и выносок.

## Голос
- Русский язык, низкий спокойный тембр, темп ~150 слов в минуту, паузы после ключевых фраз.
- Источник голоса по порядку предпочтения:
  1. `create_voice` по записи самого героя (20–30 сек чистой речи, с согласия);
  2. если записи нет — подбор ближайшего по тембру из `list_voices`, с пометкой «не голос героя».
- Фирменные фразы:
  - открытие: «Стоп. Прежде чем покупать дверь…»;
  - закрытие: «Дверь без ошибки — Империя дверей. Напишите плюс — подберём вашу».

## Как фиксируется лицо в Higgsfield
1. Фото загружаются через `media_upload_widget`; их media_id записываются ниже.
2. По workflow `character-sheet` собирается лист персонажа (photoreal-unretouched):
   анфас, 3/4, профиль, по пояс, в полный рост.
3. Во всех кадрах с героем лист персонажа и 1–2 исходных фото передаются в `image_references`
   (seedance_2_0 / seedance_2_5 в режиме omni_reference).
